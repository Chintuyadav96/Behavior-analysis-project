PROPOSED SYSTEM:
In this project student want to detect people’s mental behavior by analyzing there’s emotions and to implement this project we have used Facial Expression dataset and 
SVM machine learning algorithm. SVM is trained with facial expression dataset and then SVM trained model can be used to detect human mental behavior.
MODULES:
1) Webcam connection: using this module application will be connected to live webcam
2) Load & Preprocess Dataset: using this module application read all dataset images from numpy array and then normalize and extract features from images.
3) Train SVM Algorithm: Extracted features will be used to train SVM algorithm
4) Capture Person: using this module we will capture person image and then detect face from that image
5) Detect Emotion: This module will take detected face as input and then by using SVM algorithm will predict person mental behavior as SAD, HAPPY, NEUTRAL, ANGRY etc.
ADVANTAGE:
This project make efficient for the Psychiatrist , who can treat more than two patients at a time by observing their mental behaviour using facial expression.
